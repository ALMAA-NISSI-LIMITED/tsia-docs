🔐 All keys must be provided securely — never committed to version control. Production keys go into server environment variables or the .env file. Mobile keys are injected at build time via --dart-define. Keys marked Client to provide require the client to create accounts and generate credentials.

Surface Method Details
Rider & Driver (mobile) OTP (phone) 6-digit code via SMS (Africa's Talking). 5-min expiry, 5 attempts max, 30s resend cooldown. Social login (Google, Apple) also supported
Admin dashboard Email + password Laravel Breeze session auth + optional Google Authenticator 2FA with recovery codes. Session times out after 30 min idle
