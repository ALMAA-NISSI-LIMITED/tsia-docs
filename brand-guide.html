Logo · Rules

Do and don't

Keep the mark legible and on-brand at every size.

✓ Do
  • Use on white, navy, or solid green only
  • Maintain a clear space equal to the mark height on all sides
  • Scale proportionally — never stretch
  • Use the white version on dark or colored backgrounds
  • Minimum display size: 24px height
✕ Don't
  • Place on busy photography or gradients
  • Recolor the mark to any non-brand color
  • Add drop shadows or effects
  • Use the dark mark on dark backgrounds
  • Combine with the SafiRides wordmark — they are distinct brands

Voice & Tone

How we write

The platform serves drivers, riders, and fleet operators across Kenya. Write plainly and act on behalf of the person at the screen.

PrincipleInstead ofWrite
Action labels say what happensSubmit · OK · ConfirmPublish fare · Approve driver · Cancel ride

Errors say what and how to fixAn error occurredOTP expired — request a new one

## TSIA Brand Context
# Prepend to any prompt that involves building TSIA UI.
# TSIA = Transport Systems Infrastructure Africa — Kenyan ride-hailing platform.

### Colors
Primary Green   #00873E  — actions, links, active states (light mode)
Spring Green    #2FD36A  — accent variant for dark surfaces
Brand Navy      #0E1B2A  — primary text, sidebar, dark surfaces
Page Ground     #F2F2F5  — light-mode page background
Card White      #FFFFFF  — card and navbar surface
Night Ground    #0A1219  — dark-mode page background
Dark Card       #131F2E  — dark-mode card surface

### Semantic Colors (never decorative)
Success  #4FD69C  completed, verified, online
Warning  #FC7C5F  pending, review needed
Danger   #F5365C  error, SOS, blocked
Info     #37D5F2  informational, neutral alerts

### Typography
Primary face : DM Sans   — ALL UI text, no exceptions
Data / mono  : DM Mono   — IDs, amounts, timestamps, tokens only

Type scale:
  Page title   DM Sans 800 · 35px · tracking -0.03em
  Section head DM Sans 700 · 24px · tracking -0.02em
  Card title   DM Sans 600 · 18px · tracking -0.01em
  Body         DM Sans 400 · 16px
  Caption/meta DM Sans 500 · 13.5px
  Eyebrow/label DM Sans 600 · 11px UPPERCASE · tracking +1.8px

### Spacing (8pt grid)
4 · 8 · 12 · 16 · 24 · 32px — minimum tap target 48px

### Border Radius
8px    chips, badges, small buttons
12px   cards, inputs, standard buttons
16px   modals, bottom sheets, large cards
9999px pills, tags, avatar rings

### Motion
Micro      150ms easeOutCubic  hover states, toggles
Standard   280ms easeOutCubic  panel reveals, toasts
Emphasis   420ms easeOutCubic  page transitions, drawers
Sheet open spring()             bottom sheets use spring physics

### Voice Rules (non-negotiable)
- Action labels: say what happens    "Approve driver" not "Submit"
- Amounts: always include currency   "KES 1,240" not "1,240"
- Errors: what went wrong + how to fix  "OTP expired — request a new one"
- Times: append timezone             "14:32 EAT" not "14:32"
- No apologies in copy               "Couldn't load rides — retry" not "Sorry…"
- Audience: Kenyan drivers, riders, fleet operators — write plainly

This block encodes the complete brand constraint set. Use it as a prefix for any of the platform-specific prompts below, or paste it standalone into any LLM session before asking for UI code.

Flutter · Android & iOS 
## TSIA Flutter Instructions
# For building Android & iOS screens for the TSIA ride-hailing app.
# Paste the Universal Brand Context block above this prompt as well.

### Stack
Flutter 3.x · Dart · Material 3 base theme
State   : Riverpod (preferred) or Provider
Routing : GoRouter with named routes
Fonts   : google_fonts package — GoogleFonts.dmSansTextTheme()

### ThemeData (light)
ThemeData(
  useMaterial3: true,
  colorScheme: ColorScheme.fromSeed(
    seedColor: Color(0xFF00873E),
    brightness: Brightness.light,
  ).copyWith(
    primary:    Color(0xFF00873E),
    onPrimary:  Color(0xFFFFFFFF),
    surface:    Color(0xFFFFFFFF),
    onSurface:  Color(0xFF0E1B2A),
    background: Color(0xFFF2F2F5),
    error:      Color(0xFFF5365C),
  ),
  textTheme: GoogleFonts.dmSansTextTheme(),
)

### ThemeData (dark)
colorScheme: ColorScheme.fromSeed(
  seedColor: Color(0xFF2FD36A),
  brightness: Brightness.dark,
).copyWith(
  primary:    Color(0xFF2FD36A),   // spring green on dark
  surface:    Color(0xFF131F2E),
  background: Color(0xFF0A1219),
)

### Component Rules
Tap targets    : 48×48px minimum — enforce with SizedBox or padding
Cards          : Container, borderRadius 12, elevation 0, color Colors.white
Primary button : FilledButton, shape RoundedRectangleBorder(radius 12)
Text fields    : OutlineInputBorder radius 12, focusedBorder #00873E
Bottom sheets  : DraggableScrollableSheet with spring animation
Chips / badges : borderRadius 9999 (full pill)

### Amounts & Formatting
Currency    always prefix "KES " — never show raw numbers
NumberFormat.currency(locale: 'en_KE', symbol: 'KES ', decimalDigits: 0)
Times       append " EAT" — use TZDateTime from timezone package
TZDateTime.from(dt, getLocation('Africa/Nairobi'))

### Platform Targets
Android 8+ (API 26) · iOS 15+
Maps        : google_maps_flutter
Real-time   : socket_io_client (WebSocket to Node.js service)
Push        : firebase_messaging + flutter_local_notifications
Payments    : trigger M-Pesa STK push via backend REST — no card UI in Flutter
OTP / SMS   : Africa's Talking backend endpoint — not a client SDK

### File / Feature Structure
lib/
  features/
    auth/          — OTP login flow
    rides/         — booking, tracking, history
    payments/      — M-Pesa, wallet, receipts
    driver/        — driver-only screens (separate app)
  shared/
    theme/         — ThemeData, color constants
    widgets/       — reusable components
    utils/         — formatters, validators

Append this block after the Universal Brand Context when asking an LLM to build Flutter screens, widgets, or themes for either the Rider or Driver app.

# For building the TSIA admin dashboard (React 18 + Vite).

### Stack
React 18 · Vite · React Router v6 · React Query (TanStack)
CSS: Tailwind CSS v3 — utility-first, one approach, no mixing with raw CSS

### Tailwind Config  (tailwind.config.js)
colors: {
  'tsia-green':  '#00873E',
  'tsia-navy':   '#0E1B2A',
  'tsia-spring': '#2FD36A',
  'page':        '#F2F2F5',
  'night':       '#0A1219',
  'success':     '#4FD69C',
  'warning':     '#FC7C5F',
  'danger':      '#F5365C',
  'info':        '#37D5F2',
},
fontFamily: {
  sans: ['DM Sans', 'ui-sans-serif', 'system-ui'],
  mono: ['DM Mono', 'ui-monospace'],
},
borderRadius: {
  DEFAULT: '12px', sm: '8px', lg: '16px', full: '9999px',
},

### Component Conventions
Page layout : sidebar nav + main content, bg-page dark:bg-night
Cards       : bg-white dark:bg-[#131F2E] rounded-[12px] shadow-sm
Primary btn : bg-tsia-green text-white rounded-[12px] hover:bg-[#006830]
              min-h-[48px] font-semibold transition-colors
Table thead : text-[11px] uppercase tracking-widest text-tsia-navy/40 font-semibold
Status pill : rounded-full px-3 py-1 text-xs font-semibold
              success → bg-success/15 text-success
              warning → bg-warning/15 text-warning
              danger  → bg-danger/15 text-danger
KPI / stat  : DM Sans 800 number + DM Mono currency prefix

### Formatting
Currency Intl.NumberFormat('en-KE', { style: 'currency', currency: 'KES' }).format(n)
Time     luxon — always convert to 'Africa/Nairobi' and append ' EAT'
DateTime.fromISO(iso).setZone('Africa/Nairobi').toFormat('HH:mm') + ' EAT'
Dates    toFormat('d MMM yyyy') — no ambiguous numeric formats

### API Contract (Laravel backend)
Base URL    /api/v1/
Auth        Bearer token (Sanctum) via Authorization header
Pagination  { data: [], meta: { current_page, last_page, total } }
Errors      { message: "…", errors: { field: ["…"] } }
Success     HTTP 200/201 with { data: {…} }

### Forbidden Patterns
- No hardcoded hex values in JSX — use Tailwind tokens only
- No bare number display — always KES-prefix monetary values
- No direct fetch() — always use React Query (useQuery / useMutation)
- No inline styles for spacing — use Tailwind gap/p/m utilities

Use this when asking an LLM to build dashboard pages, data tables, charts, or components for the React-based admin frontend.

### Blade Formatting Helpers
Currency   {{ 'KES ' . number_format($amount, 2) }}
           // NEVER: {{ $amount }} alone
Time (EAT) {{ $datetime->setTimezone('Africa/Nairobi')->format('H:i') }} EAT
Date       {{ $date->format('j M Y') }}   // e.g. 27 Aug 2026
Percent    {{ number_format($pct, 1) }}%

### Status Badge Colors  (via inline style — SCSS maps below)
Online / completed  bg #4FD69C  text #0E1B2A
Pending / warning   bg #FC7C5F  text #fff
Error / danger      bg #F5365C  text #fff
Info / neutral      bg #37D5F2  text #0E1B2A

### Forbidden Patterns
- No hardcoded hex in Blade — use Bootstrap utilities: text-primary, bg-primary, btn-primary
- Never edit compiled CSS in public/ — edit SCSS source and recompile
- Never display monetary values without the KES prefix
- No raw PHP output without escaping — always {{ }} not {!! !!} for user data

Use this when asking an LLM to build server-rendered admin pages, Blade components, or SCSS changes for the Laravel backend.
