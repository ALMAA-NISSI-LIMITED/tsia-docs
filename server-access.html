Connecting

Tailscale required. SSH is restricted to the Tailscale network. Connect to Tailscale before attempting SSH.
Quick connect (SSH config)
ssh tsia-gcp

Requires ~/.ssh/config entry below. Resolves to tsia-gcp@100.124.221.68 over Tailscale.

Full command
ssh -i ~/.ssh/tsia_gcp tsia-gcp@100.124.221.68

SSH Config Entry

Add to ~/.ssh/config on your local machine:

Host tsia-gcp
  HostName 100.124.221.68
  User tsia-gcp
  IdentityFile ~/.ssh/tsia_gcp
  IdentitiesOnly yes

New Developer Access

1
Generate an SSH key pair
Use ed25519. Replace your-name with something identifiable.
ssh-keygen -t ed25519 -C "tsia-gcp-your-name" -f ~/.ssh/tsia_gcp
2
Share your public key with an admin
The admin adds it to the VM via GCP Console → Compute Engine → VM → Edit → SSH Keys.
cat ~/.ssh/tsia_gcp.pub
3
Join the Tailscale network
Install Tailscale and ask an admin to invite your account to the TSIA tailnet.
# macOS
brew install tailscale

# Ubuntu / Debian
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
4
Add SSH config and connect
Host tsia-gcp
  HostName 100.124.221.68
  User tsia-gcp
  IdentityFile ~/.ssh/tsia_gcp
  IdentitiesOnly yes
ssh tsia-gcp

Firewall Rules

Port 22 (SSH) 100.64.0.0/10 (Tailscale CGNAT) only
Port 80 / 443 0.0.0.0/0 — public web traffic

Port 22 must not be open to 0.0.0.0/0. If the GCP default-allow-ssh rule is active, update its source range to 100.64.0.0/10.
